## 无头截图排查经验（已回写进 phaser-ui-screenshot skill）

- vite 只监听 IPv6：`netstat` 是 `[::1]:5173`，**必须用 `http://localhost:5173`**；
  `127.0.0.1` 会让无头 Chrome `ERR_CONNECTION_REFUSED`、`window.__game` 永远 undefined。
- **不要用 curl 探端口**：沙盒代理对任何出网请求都返回 502，和端口在不在听无关；用 node `fetch`。
- 起 dev server 必须 `run_in_background`，`bash dev.sh &` 塞在普通调用里进程会被收走。
- 取景**不要动相机**（会和 `applyHDCamera` 打架），冻结角色后 `setPosition` + `body.reset`
  + `cameras.main.centerOn(x,y)` snap；坐标换算的唯一真相是 `cameras.main.worldView`，不是 `scrollX`。
- 探针脚本 `shot-scene.mjs`（通用场景/坐标）与 `shot-image.mjs`（放大读用户标注图）
  已收进 skill 的 `scripts/`，仓库 `tools/` 里不留临时脚本。
