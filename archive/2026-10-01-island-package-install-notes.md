本包只包含岛屿流程需要的源码、第一关结尾视频和对应声音，没有依赖目录或 Git 历史。

## 安装

1. 确认 GitHub Desktop 当前仓库是 Seek-game-demo、分支是 island-prototype。
2. 将新仓库当前的 src 文件夹复制一份到仓库外，作为备份。
3. 将本包中的 `src` 和 `assets` 两个文件夹复制到 Seek-game-demo 根目录（与 package.json 同级），选择合并文件夹。不要删除仓库原来的 `src` 或 `assets`。
4. 本次会替换 main.ts、MenuScene.ts、RoomScene.ts、EndingScene.ts，并新增 IslandScene.ts、src/island、ending.mp4 和 ending-voice.wav。如果收到本包后又改过这些同名源码，请先比对。manifest.json 保存了制作时原文件和新文件的 SHA256。
5. 在新仓库终端运行 npm.cmd run build。通过后运行 npm.cmd run dev。
6. 打开终端给出的地址，在首页点击“查看记忆之岛 · 原型”。

## 功能

- 总览：鼠标拖动旋转、滚轮缩放，六座建筑代表六个阶段。
- 进入岛屿：第三人称角色；WASD 移动、Shift 跑步、按住鼠标左键拖动转视角。
- 查看岛屿：回到总览，再进入时保留角色位置。
- 接近门口按 E，或点击屏幕交互按钮。
- 第一个建筑进入现有森林关卡；原有房间内容保持。记忆球完成后先播放第一关结尾动画，播放完或跳过后再进入记忆之岛。
- 首次完成房间会点亮第一座建筑，进度保存在该浏览器的本地存储中。
- 后五关只有入口占位；尚未制作的关卡不会假装通关。
- 这是桌面键鼠原型，还没有触屏移动按钮或正式人物模型。
