# 第二关夜晚骑楼场景资产

## PR 说明

### 目的

把第二关“骑楼街逃课”的灰盒替换为夜晚江南骑楼正式场景，并保留原关卡的折返路线、跳跃节奏、手电筒追踪、阴影躲避、动态障碍、检查点和出口逻辑。

### 本次内容

- 一张 `3680 × 1100` 的连续夜晚骑楼背景。
- 9 段与灰盒完全同坐标的平台素材。
- 9 个固定障碍、10 个阴影遮挡模块、2 个摆动物、1 面封路墙。
- 值班老师、第二记忆房入口和终点收集物。
- 收集物已从“旧票根”正式改为“一张旧钞票”；图片、标签、拾取与门前提示均已同步。
- `ChapterTwoNightArt.ts`：所有美术资产的运行时坐标与尺寸。
- `ChapterTwoChallengeScene.ts`：已接入全部素材，同时保留最新 `main` 的统一角色动画加载方式。
- 两张评审预览和完整提示词记录。

### 运行方式

```bash
npm install
npm run dev
```

打开：

- `http://127.0.0.1:5173/?scene=chapter2`
- `http://127.0.0.1:5173/?scene=chapter2&artPreview=1`（美术检查模式）

### 队友接入须知

1. 不要修改 `geometry.json` 与 `ChapterTwoNightArt.ts` 中的平台坐标，除非同时修改灰盒碰撞。
2. `p01`–`p09` 是底图缺口的对应填片，必须与底图一起加载，位置不能进行自动平铺或平均分配。
3. 障碍和遮挡素材以 2 倍像素导出，游戏内按 `0.5` 显示；平台与底图按 1 倍显示。
4. 遮挡图是视觉物和躲避区域，不是额外实体碰撞。实体碰撞继续使用原灰盒的 26 像素宽矩形。
5. 摆动物的轴心在上端中心，角度沿用 `-sin(time × 0.0021 + phase) × 0.82`。
6. 老师的光锥是实时玩法反馈，不应烘焙进背景。
7. 旧钞票的内部道具 ID 仍为 `memory-token-2`，避免破坏第二记忆房入口参数。

## 画风说明

场景采用已经确认的手绘动画方向：深色但有轻重变化的轮廓，水彩与水粉概括色面，减少写实碎纹理。夜色以灰蓝、黛青和灰绿为主，暖窗灯、小灯笼、水面倒影、窗台花草、竹帘和藤蔓提供生活气息。装饰避开平台边缘和下落口，确保人物、跳跃落点与光锥仍清晰可读。
