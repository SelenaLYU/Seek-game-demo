# 第三章画中世界：两段解谜美术规划

范围：当前的「透视错位／景物变形」与「借色复苏」两段连续解谜。两段都是户外画中世界，不制作室内房间、画框或屏幕内人物。本文件是制作计划，尚未生成或接入正式美术。

## 共同视觉规范

- 延续现有游戏的温暖手绘笔触、纸面色块和柔和轮廓；画中世界允许反常重力、倒悬植物、空中游鱼，不走写实路线。
- 两段统一纸纹、描边、光照方向、植物与印记造型。第一段较安静，第二段从褪色逐步变得明亮梦幻。
- 开始时也保留少量原生色源：橙色落日与蓝云。绿色随鲸鱼浮起显露，紫色由种子开花产生。
- 色彩用途要可辨认：蓝色的轻盈和雨水、橙色的温暖、绿色的连接、紫色沿开花根系进入倒影。
- 图片里不烘焙物体名称、操作说明、英文、按钮或固定提示箭头。开场中英文由程序排版、逐句淡入淡出。
- 原色源与染色目标都保留颜色，不能把“借色后变灰”作为状态图。
- 可交互物的轮廓与体量要足够明显；通过亮度、轻微运动、局部色彩引导观察，避免靠文字牌说明。

## 第一段：透视错位——风把远方折起来

当前灰盒机制：拉动金色线结，树木、岩石、坡地和三段笔迹一起连续变形；对齐后出现可点击印记，进入借色场景。第一段是一片连续的自然画境，不出现浮岛、断开的陆块、鲸鱼或建筑，也不需要制作角色和可行走楼梯。

构图方向：玩家面对一片从近景延伸到远方的完整山谷。近处是草坡与岩石，中景由树木、溪水和石坡形成三组明显层次，远处是低矮山体与云雾。初看时，三组景物像正常风景，但藏在树枝、岩石裂缝和水纹中的三段弧线彼此错开；拖动线结后，整个山谷的纵深关系被重新折叠，远近景在一个特定视角拼成完整的圆。

| 素材组 | 要画什么 | 拆分与状态 |
| --- | --- | --- |
| 天空与远山 | 柔和天色、远处山体、山间色雾、少量画纸肌理 | 天空静态；远山与雾各自分层，参与轻微纵深变化；边缘留可裁切余量 |
| 连续坡地 | 从前景延伸至中远景的草坡、土坡和地面色块 | 保持视觉上连续；按近、中、远三个纵深区切层，切口藏在草丛、岩石或雾里，不能画成悬空陆块 |
| 岩石组 | 左侧近景岩石、中部裂石、右侧石坡与零散小石 | 大岩体、前方遮挡石、小石分别出图；岩石裂缝承担一段圆弧线索 |
| 树木与灌木 | 一棵近景弯曲树、一棵中景树、远处小树与灌木 | 树干、主要树枝、树冠分开；树枝走势承担一段圆弧线索，根部必须自然落在坡地上 |
| 溪水与水面 | 从远处穿过石缝、流向前景的自然溪流或浅水面 | 水体、岸边、亮边和水纹分开；水纹承担一段圆弧线索，不做空中水带和断流机关 |
| 云与风的笔迹 | 云团、山雾、稀疏风线和少量漂浮笔触 | 透明图层，可复用少量不同形状；只强化空间流向，不能遮挡三段圆弧 |
| 错位圆弧 | 分别藏在树枝、岩缝与水纹中，对齐时组成完整圆 | 先在正确构图里画完整圆，再按三个自然载体拆分；圆弧应像景物本身的笔触，初始状态不能一眼看出答案 |
| 可拉动线结 | 自然融入风中的金色线结与细丝 | 本体与光晕分开；拖动反馈由程序处理 |
| 固定前景参照 | 画面底部草叶、碎石、一小片圆形花瓣或水洼 | 固定不变，用来让玩家看出世界正在发生透视变化；圆形元素只是暗示，完成奖励仍是印记 |
| 完成印记 | 不规则、带笔触的抽象印记 | 印记本体与辉光分开；可与第二段共享设计语言 |

先做三张构图稿：正确对齐、初始错位、拖动中间状态。三张都必须是同一片连续山谷，树、岩石、溪水的身份和位置关系保持一致。定稿以“正确对齐”的画面为坐标母版，不让三张图各自重新生成不同景物。

接入方式：后续使用带纹理的二维网格连续变形，谜题笔迹必须与所在景物共用变形坐标；不能只用两张整图淡入淡出，也不能只横向移动 PNG 冒充透视。当前灰盒绘制的是程序图形，正式贴图的网格变形与接缝处理仍需实现和验证。

变形分区之间不能出现黑缝、天空穿帮或陆地被拉成悬浮碎片。草丛、岩石前景、岸线和山雾负责遮接缝；规则的树干轮廓和岩石裂纹不能跨过分区边界。完整圆对齐、线结可见、极限拖动不露白，是这一段的验收重点。

## 第二段：借色复苏——鲸鱼托起整个世界

构图母版：最大的鲸鱼位于底部；左侧根系岛、中间花园岛、右侧湖泊岛都落在它背上，岛间留距离。最终树与门向上生长，不能挤住色源或完成轮环。

| 素材组 | 要画什么 | 拆分与状态 |
| --- | --- | --- |
| 世界底景 | 失色的天空、色雾与复苏后的光色 | 同构图两种氛围；纸纹共用，不另画两套不同地形 |
| 巨鲸 | 温柔、像承载大地的鲸鱼 | 身体、尾巴、胸鳍、眼睛分开；闭眼／睁眼两套眼睛；橙色暖光与蓝色染色独立，允许同时保留 |
| 三块岛 | 根系岛、花园岛、湖泊岛 | 三岛分别出图，草面与悬垂部分分层；标出与鲸背的接触位置 |
| 原生色源 | 橙色落日、蓝色云、绿叶 | 各自独立透明图；借色前后保持原色。绿叶显露的遮挡层单独保留 |
| 降雨云 | 右上方白云，借到蓝色后变成雨云 | 同轮廓白／蓝两状态；雨滴用少量笔触粒子循环，不需长视频 |
| 根系网络 | 根结、去花园与湖泊的两条根 | 根结独立；枝根基础纹理／分段素材供程序逐渐显露，水与色的流动另做光点 |
| 种子与土壤 | 三颗可观察的种子、种床、湿润水痕、暖色微光 | 干／湿与冷／暖可独立组合，支持先浇水或先给温暖 |
| 发芽与紫花 | 幼芽、伸长的茎叶、花苞、开放紫花 | 茎叶、花瓣、花心分层，支持依次生长；开放花瓣必须容易点击，借色后花仍盛开 |
| 湖泊与倒影 | 湖面、水纹、树影、门影、可选花影 | 湖水独立，三个倒影分别出图；前期低饱和，紫花开放后允许紫色沿根进入水面 |
| 倒影成真 | 生长到空中的树、承托门的树枝、梦幻小门 | 树干、枝条、树冠、门独立；倒影与实体必须造型对应，树出现后能直观理解它可以托门 |
| 轮环与最终印记 | 四处颜色缺口、抽象印记 | 环体、四个色槽、印记与辉光分开；无文字；图案可帮助区分四个槽 |
| 世界复苏点缀 | 少量空中鱼、花粉、星点、风线 | 小型可复用透明素材；程序循环运动，控制数量，保持主体与交互清晰 |

第二段不制作断流河流、不制作底部色盘按钮、不制作任何物体名称牌。开场文字由程序显示；提示、返回和重试是少量通用 UI。

## 文件交付方式

1. 先交完整构图预览，再交可编辑分层源文件（如 PSD），以及各层的透明 PNG。预览整图用于对照，不直接承担所有交互。
2. 构图稿可统一用 2560×1600（16:10）工作画布。第一段现有逻辑约 11:7，第二段为 16:10；接入时分别保留坐标与安全区，不直接拉伸成同一比例。
3. 关键线结、种子、色源、花和印记放在兼容宽屏的中央安全区。远景向外补画，验收时同时看 16:9 与 16:10 的裁切。
4. 互动对象按最终屏幕显示尺寸约 2 倍绘制；不要把小图放大冒充高清，也不需要每棵草都导出全屏图。
5. 同一物体的状态图必须来自同一母版，保持画布尺寸、位置、轴心和外轮廓一致。不同状态不能随机换角度或比例。
6. 母版保留完整坐标；小图若裁切透明边，随交付记录它在母版中的位置、尺寸、轴心与所属父对象。鲸鱼、岛群、植物的从属关系要明确。
7. 提供局部色彩遮罩：至少覆盖鲸鱼蓝色／橙色、雨云、根结、种子温暖、紫花与最终槽位。根据对象需要着色或揭露，避免全图统一滤色误伤色源。
8. 发光、雨、漂浮、轻微摆动和淡入淡出以程序动画为主；先验证分层效果，确需逐帧手绘的动作再补帧，不先生成整段背景视频。

## 建议制作顺序

1. 先定四张关键构图：第一段初始／对齐；第二段失色／完全复苏。统一画风和色彩关系。
2. 优先做第一段“最容易出技术问题”的小样：一段连续坡地、一组岩石、一棵树与一小段溪水。接入连续变形，验证坡地不会被拉成浮岛、接缝能被自然遮住、三段圆弧能够精确对齐，再扩成整景。
3. 做第二段巨鲸与三岛，把主体大小、接触关系和前后遮挡确定下来。
4. 做落日、云、绿叶、种子到紫花这一条完整交互素材链；先保证不用文字也能辨认和点击。
5. 补湖面倒影、实体树与门、两段印记，然后统一风、雨、漂浮生命与结束氛围。

验收：两段无画框、无人物；第一段是连续的树木、岩石、坡地与溪水风景，无浮岛，能够连续变形并让三段自然笔迹对齐成圆与印记；第二段才出现由鲸鱼承载的岛群，并满足借色不褪色、雨与暖两种顺序都能开出紫花、场景无名称牌与底部色盘、色源及目标不会被装饰遮挡。
