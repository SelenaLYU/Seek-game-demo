# 第一阶段：单点透视 / 平涂

保留原风格母版和用户确认的错位构图参考。当前运行时仅使用：
- `valley-flat-ground.png` / `.webp`：完整连续草坡、森林、远山与云。
- `valley-flat-scenery.png` / `.webp`：没有附带草地矩形的树、岩石、溪岸图集。

PNG 为美术原稿；运行时使用同尺寸无损 WebP。此前点状厚涂版本的临时背景和图集已移除。

## 实现

一个风结控制同一视点。树、岩石、溪岸放在不同深度，通过同一个相机投影产生位移、缩放与方向变化；地面是一张连续的网格，外边缘固定覆盖画面。所有景物使用 GPU 三角网格共享边缘，不再使用 Canvas 三角裁切叠加，以免透明边缘产生网格缝。判定检查实际景物轮廓的三个投影接点，没有绘制独立圆线。

## 生成记录

使用内置 imagegen 编辑上一版素材。最终提示词重点：

背景：保持低视角与连续山谷构图，改为大面积统一平涂色块。米白云、灰蓝远山、鼠尾草绿坡地、赭黄沙地、深绿树丛；树冠只用几个大的不规则色块，岩石只用两三个面。去掉点描、颗粒、厚涂、碎叶、草点、画布肌理。不添加圆环、人物或文字。

景物：保持原图集中的位置和内侧轮廓，配色与平涂背景一致。树冠用 5–8 个色块，树干两色，岩石三个面，溪水两色。去掉树和岩石下方的草地/泥土矩形，改为自然根部、岩石与灌木透明轮廓；溪岸去掉厚重的土地底座，保留窄水面和岸线。真正透明背景，不画圆弧或发光线。
