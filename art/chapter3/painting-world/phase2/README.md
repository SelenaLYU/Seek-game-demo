## 生成提示词摘要

共用：严格参考已确认圆弧母版，透明柔和水彩、暖纸白、蓝橙绿紫配色、圆弧坡面；无硬平台、无建筑、无人物、无文字。各分层要求：
- 天空：移除鲸、地形、植物、太阳和可交互云，只留稀疏纸色云雾与圆润远景。
- 鲸：只提取完整蓝鲸，尾在左、头在右，保留柔和羽化边缘，透明底。
- 地形：三座连成一体的圆润坡地，左低、中高、右湖泊；无树花鲸，底边水彩消散。
- 植物：六项独立图集，树、钟形花、粉树、三颗种子、根结、根蔓门；清理背景光晕并留透明间距。
- 特效：六项独立图集，太阳、蓝云、浅云、飞鱼、水滴、抽象金色印记；真实透明背景。
- 藤蔓：一条细长、轻轻下弯的绿色水彩藤蔓，少量叶片，无密集根须、无光晕。

完整关卡验收：普通点击借色通关、蓝色不能提前唤醒鲸鱼、两条根连接、下雨浇种子、橙色使花开放、紫色解开树影和门影、四个颜色槽、印记、窄屏重排与重试。构建通过后再发布，当前仅本地替换。

发布格式：上表 PNG 为原稿；运行时直接引用同名无损 WebP。六张图逐像素校验 RGBA 一致，保留水彩透明边缘；图片优化脚本也对本目录使用无损编码。

交互辨识调整：未完成的根结、种子、雨云和倒影独立保持较深灰色水彩，不随地形恢复颜色；太阳唤醒鲸鱼时先用保留纹理的金黄色映射，借蓝色后恢复蓝鲸。门影与真实门放大，轮环落点扩大并增加颜色轮廓及色样；点击后的阶段反馈短暂显示。
