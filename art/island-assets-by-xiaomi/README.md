## 世界观与交互逻辑

记忆之岛代表韩梅梅一生的六个阶段。玩家每完成一关，对应建筑及周边区域由灰色剪影恢复颜色，并开放下一座建筑。角色走到建筑门口即可触发进入关卡，不需要制作可见室内。

六座建筑按故事顺序为：贝壳屋、辣条屋、画室狗窝屋、粉紫树屋、海边帐篷屋、相册书屋。全岛使用梦幻、治愈的手绘水彩动画风格，并融入江南与中式结构语言。

## 3D 建模注意事项

1. 三视图从左到右依次为正面、右侧面、背面。
2. 正门必须清楚可辨，作为角色靠近后触发交互的定位点。
3. 建模时优先还原整体剪影和主要色块，花草、灯笼及包装纹样可作为简化贴图。
4. 六座建筑应保持统一的人物门洞尺度，避免每座建筑看起来属于不同世界。
5. 贝壳屋和辣条屋的主体就是物件本身，不是在普通房屋上加贝壳屋顶或辣条招牌。
6. PNG 带透明通道，便于查看轮廓和制作建模参考板。
