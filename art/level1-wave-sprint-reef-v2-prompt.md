# 第一关浪前冲刺礁独立素材（v2）

## 用途

只替换 `wave-sprint`（浪前冲刺礁）这一个关卡元素，其他六块礁石继续使用 `assets/level1/level1-stepping-reef-v1.png`，不要批量重生成。

旧素材是 1774×887 的整组礁石图，游戏里缩放为 0.24 后画面宽约 426 world px，但可站立碰撞面仅约 113 world px；它又与相距 100 world px 的 `wave-climb` 重叠，产生视觉穿帮。新素材必须是一块独立、边界清楚的石礁，避免同一组岩石轮廓重复叠在一起。

## 生成提示词

> 为横版 2D 平台游戏绘制一块**单独、完整、透明背景**的江南海岸礁石跳台素材，水彩水粉手绘动画风格。只画一块独立礁石，不要画第二块石头，不要岩石群、海浪、沙滩、海面、地平线、背景、投影底板、文字、UI、人物或标志。
>
> **侧视游戏资产，轮廓易读。** 一块暖灰、浅赭石与蓝灰色交错的海蚀岩，表面有少量低饱和苔痕和手绘深褐色细轮廓。石头上部有一段清楚、足够宽的近水平可站立顶面；顶面横向居中，轮廓简单连续，顶面高度不得被尖峰、坑洞、植物或碎石打断。顶面两端各有明显短斜坡，之后以清楚的垂直/陡斜岩壁收窄到底部；底部轮廓完整，不带泡沫或水花。
>
> 构图必须紧凑：石头本体宽约为可站立顶面宽度的 1.4–1.5 倍，高约为本体宽度的 0.55–0.7 倍，四周保留少量透明留白。顶面水平误差极小、可从远处辨认；左右外轮廓与底部透明分离，不得与画布边缘相连。透明区域必须是真 alpha，不要白底、棋盘格、阴影雾或渐变背景。适合作为独立 PNG 图层缩放到约 160–180 游戏逻辑像素宽。
>
> 画风匹配《Seek》第一关现有水彩礁石：柔和夏日光照、概括的大色块、手绘不规则边缘、克制的水彩颗粒；保持与现有素材协调，但形状必须与现有大礁石明显不同。输出单一物件、完整脚底轮廓、正交侧视，不要透视俯视。

## 导入验收（生成后必须做）

- 保存为 `assets/level1/level1-wave-sprint-reef-v2.png`，保留 alpha；不要覆盖通用礁石素材。
- 根据生成图实际像素重新量出 `standLeft / standRight / standTop / contentBottom`，不沿用旧图坐标。
- 只把 `wave-sprint` 的美术 key 与 stand profile 指向新图；其他六个 role 不动。
- 通过 alpha 像素脚本确认顶面平整度、站立区宽度及画面/碰撞映射；浏览器截图叠加临时碰撞线确认无重叠后再移除调试线。
- 实际按键完整跑通起点至冲刺礁，记录每次落地的 `body.bottom === colliderTop`，不可用 teleport 或注入速度代替验收。
