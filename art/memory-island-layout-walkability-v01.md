# 记忆之岛俯视通行规划图 v01

配套图片：`memory-island-layout-walkability-v01.png`；矢量源文件：`memory-island-layout-walkability-v01.svg`；概念底图：`memory-island-concept-base-v01.png`。

## 坐标和来源

- 这版按用户提供的概念图重新组织视觉关系：贝壳屋左下、辣条屋左上、画室上中、相册右上、树屋右侧、帐篷右下；底图用生成插画表现海岸、浅滩、植被、码头与石路。
- 已按用户在规划图上的红框标注重新移动 01、02、04、05、06 的建筑图标、入口点与路径终点；03 未标注，保持原位。码头标牌也移回靠岛一侧。
- 为贴近概念图，视觉方向设为右 `+X`、下 `+Z`、上 `-Z`。右侧列出 `MemoryIsland.ts` 当前六个入口的源坐标；概念插画中的入口位置与路线是视觉规划示意，不是这些坐标按比例投影后的精确定位。
- 虚线圆表示建议保留的门前接近空间，大小不按运行时 `2.8` 单位精确缩放；点位和建筑图标是概念占位。红色虚线仅表示需要程序核对碰撞的区域，不代表已完成最终 footprint 测量。

## 路线与门点

入口 01 至 06 分别是贝壳屋、辣条包装屋、画室狗窝屋、粉紫树屋、海边帐篷、相册书屋。红点表示入口接近点示意。程序中的 treehouse（04）当前 `yaw = -π/4`，最终入口图标需按模型朝向再对齐。

图中点线按概念图中的石路绘出，供讨论主路和六处支路的视觉连续性。它不是当前 `lane()` 折线的坐标复刻，也不是导航网格。运行时道路继续使用源码中的道路，玩家可以离开铺装路自由移动。

## 需要程序/整合验收的点

- 当前 `allowed()` 会拒绝距离溪流中心线小于 2.5 个源单位的位置；两座木桥虽然绘制在溪流处，但 `allowed()` 没有桥面例外。桥的实际可通行性需实走验证，并可能要给桥面加入通行例外。
- 这版先确定视觉布局和接近空间；要转成施工/碰撞图，需要按程序坐标重投影并使用最终 GLB 重新量测六栋 footprint。
- `allowed()` 会拒绝距离溪流中心线小于 2.5 个源单位的位置；两座木桥没有桥面通行例外。桥的实际可通行性需实走验证。
- 树干、岩石和其他装饰若需阻挡角色，应按底座占地补碰撞盒；树冠和屋檐不应默认扩大地面碰撞。

## 导出

SVG 是可编辑母版，引用同目录的概念底图 PNG；预览成品为 2400×2400。把这版视觉规划落实到游戏前，还需与固定程序坐标及现有路线做一次逐点校核。
