# 李雷角色设定与游戏资产

本目录保存《Seek》中李雷的角色建模和游戏内交互姿势。李雷是年年的儿时玩伴与后来的爱人；第四关围绕两人在小镇、河道和面馆中的共同记忆展开。

## 当前确认造型

| 文件 | 内容 | 原始尺寸 |
| --- | --- | ---: |
| `lilei-child-model-sheet-v4-floral-shorts.png` | 童年李雷正面、右侧面、背面三视图 | 1536×1024 |
| `lilei-child-crouch-back-interactive-v1.png` | 背对镜头蹲下的可点击交互姿势 | 1278×1230 |

两张图片均为带透明通道的 RGBA PNG。`v1` 至 `v3` 为设计过程稿；后续身份、服装和动作制作应以 `v4` 为准。

## 童年造型

- 六至七岁，圆宽脸、饱满脸颊、小内双、粗平眉、宽鼻头和较明显的耳朵，与年年的脸型和神态明确区分。
- 身形肉乎乎而敦实：圆肩、小肚子、厚手、粗腿和宽脚；气质憨厚、温和、可靠。
- 深棕色短发采用圆润蓬松的整体轮廓，只保留少量自然翘发。
- 穿朴素暖白棉短袖和靛蓝中式花布短裤。裤子使用低饱和砖红、暖白小花与灰绿色叶纹，并保留小补丁。
- 赤脚；童年版不使用围裙、厨师服、面碗或其他成年职业符号。

## 固定画风

- 以年年确认版为线条、水彩材质和动画信息密度基准，但不复用年年的五官、身体轮廓和表情模板。
- 使用暖棕色细手绘轮廓，线条略有压力变化和自然断开，不使用粗黑矢量勾边。
- 使用柔和哑光水彩与水粉色块、可见纸张和颜料颗粒，以及克制的块面阴影。
- 面部细节保持简洁，主要依靠脸型、眼眉、鼻子、发型、体型和服装花纹辨认。

## 蹲姿交互接入

- `lilei-child-crouch-back-interactive-v1.png` 为单姿势透明资产：李雷背对镜头稳定深蹲，像在观察地上的东西。
- 建议在 `960×540` 镜头中先按约 `80–100 px` 角色高度显示，再与年年的实际游戏高度统一校准。
- 锚点放在双脚之间的地面中心；切换到起身或回头动画时保持这个锚点不变，避免人物跳位。
- 点击热区可放在花裤衩后部的中央可读区域，但不要直接使用整张透明图片外框。
- 点击后建议先播放轻微受惊、回头、起身，再进入对话；蹲姿本身不包含 UI、点击图标或交互特效。

## 故事与后续版本

- 第四关中，成年李雷在紫色梦幻森林前方奔跑，成年年年从后方追赶；玩家追上后触发拥抱并共同进入记忆之房。
- 记忆之房位于李雷经营或继承的面馆，回忆涉及小船、星空、酸果与他为年年制作的特制面。
- 成年版应延续圆宽脸、厚实体格、暖棕眼睛和憨厚笑容，再通过面馆工作服或围裙表达职业信息。

## 童年版三维资产（2026-10-05 生成）

用 `tripo` CLI 从 `lilei-child-model-sheet-v4-floral-shorts.png` 生成，与韩梅梅使用同一套
参数（v3.1 + detailed geometry/texture + face_limit 80000），骨骼与韩梅梅逐节点一致，
可在同一场景内共用动画状态机。

### 流水线与实际花费

| 步骤 | 命令要点 | 积分 | 产物 |
| --- | --- | ---: | --- |
| 切三视图 | alpha 通道自动分块，输出方形透明底 `tripo-input/lilei-{front,right,back}.png` | 0 | 3 张 |
| 多视角生成 | `multiview-to-model`，正面/背面/右侧三视图 | 60 | `tripo-out/lilei-child-model-93299ed3/` |
| 可绑定性检查 | `tripo anim check` → `riggable: true, rig_type: biped` | 0 | — |
| 骨骼绑定 | `tripo anim rig --rig-type biped --spec tripo -p model=v1.0-20240301` | 25 | `tripo-out/lilei-rig-v1-23097ef5/`（43 节点/41 关节） |
| 四段动画 | `tripo anim retarget --animation preset:<idle\|walk\|run\|jump> --animate-in-place` | 4×10 | `tripo-out/lilei-child-{idle,walk,run,jump}-*/` |

合计 125 积分。

### 运行时资产

`public/island-models/`：`character-lilei-child.glb`（绑定后的基础模型）+
`character-lilei-child-{idle,walk,run,jump}.glb`。四段动画 GLB 已剥离网格（只留骨架与动画
轨道，55–207KB/段，`/tmp/strip_mesh.py` 的做法），与韩梅梅的轻量动画 GLB 一致——岛上代码
只读取动画片段，载入后会 `dispose` 掉 scene。

校验结果：四段各含一个同名 clip（idle 15.37s / walk 2.37s / run 1.27s / jump 2.23s），
每段 123 条轨道、41 个目标关节，与基础模型节点名**零未匹配**。

### ⚠️ 绑定必须钉版本

`tripo anim rig` 依赖默认参数会产出「肢体分段骨架」（53 节点，`tripo::0_Left_Limb_*`），
人形预设动画无法 retarget，服务端报 `1004 Invalid input parameter`。**必须显式加
`-p model=v1.0-20240301`**。完整排查与判定标准见 `decisions/2026-10-05-tripo-rig-version-pinning.md`。
