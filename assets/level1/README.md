`scene/level1-watercolor-game-background-v1-1900x540.png` 为美术基准，并作为透明图层叠加到关卡中，不烘焙进背景板。

## 美术规范

- 格式均为带透明通道的 RGBA PNG。
- 统一采用手绘水彩与水粉色块、可见纸张颗粒和少量不规则深色线条。
- 光线方向统一为右上方夏日日光；岩石使用浅赭石亮面、苍灰与蓝灰侧面、茶褐色缝隙阴影。
- 海浪以青碧水彩明暗和暖白浪沫塑形，不使用粗黑色连续勾边。
- 海鸥采用轻盈、可爱的动画造型；下方双脚是玩家的视觉抓取点，应保留清晰空间。
- 石门与可跳礁石使用同一套岩石材质和色块语言，门体嵌在连续礁岩中。

## 接入说明

- 本关逻辑世界尺寸为 `1900×540`，单次镜头为 `960×540`；最终缩放应在实际镜头中检查。
- 礁石碰撞面应贴合顶部较平整的亮色岩面，不要按整张透明图片外框创建碰撞体。
- 海鸥抓取点建议放在身体下方、双脚之间；角色悬挂时不要遮住海鸥头部和翅膀。
- 浪尖落脚点建议放在最高的暖白泡沫脊上，动态位移与碰撞体应同步。
- 钥匙拾取后再生成或显现石门；石门交互区域以木门开口为准，不包含两侧装饰岩块。
- 固定画风说明见 `art/level1-watercolor-style-prompt.md`。
