# 第二关小卖部主线交互资产（首版）

本目录保存第二关小卖部的主线交互资产母版与首轮切图。画风基准为已确认的夜晚骑楼与小卖部场景：柔和手绘动画背景、水彩/水粉色块、克制线条、暖黄室内光与靛蓝夜色。

## 母版

- `story-props-master-v1.png`：作业本、风景杂志、夹页货架图，共九个状态。
- `puzzle-goods-caps-master-v1.png`：九件谜题商品及其对应瓶盖图案。
- `collection-and-snack-master-v1.png`：门框刻度、抽屉状态、收藏物、辣条三态与地图物品栏图。

## 制作边界

- 所有资产为透明 PNG，不包含房间背景。
- 商品包装均为原创抽象图案，不使用现实品牌或可读商标。
- 中间货架正面使用九件谜题商品；普通陈列商品不属于本目录。
- 母版确认后，再按实际 Phaser 锚点与显示尺寸做最终紧边裁切和接入。
- `v1` 为美术确认稿，尚未替换灰盒代码中的占位图形。
