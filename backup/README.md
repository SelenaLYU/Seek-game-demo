# 美术探索备份

这里集中保存团队的角色、场景和独立元素试验图，以及生成提示词和美术笔记。内容用于讨论和追踪迭代，除非明确标注确认，否则都不代表正式游戏资产。

- [`character/`](character/)：角色设定、动作、转面和角色参考图。
- [`scene/`](scene/)：森林、家庭记忆房间、记忆之岛、江南/广东场景及风格参考。
- [`element/`](element/)：独立道具、植物和交互元素，等待后续补充。
- [`PROMPTS.md`](PROMPTS.md)：本轮探索提示词索引。
- [`asset-prompt-log-teammate.md`](asset-prompt-log-teammate.md)：队友归档的原始提示词与试验记录。
- [`TEAMMATE-SYNC.md`](TEAMMATE-SYNC.md)：队友素材的来源和同步说明。

文件名中的版本号用于保留探索顺序。新增试验请另存新版本，避免覆盖旧稿。
