# 童年主角探索图 v1 提示词

用于原创叙事向 2D 横版游戏角色概念探索。设计一位 5–6 岁、令人印象深刻的儿童主角，适用于关于童年记忆与家庭的故事；文化背景保持中性，不绑定特定历史年代，气质亲切、好奇而安静。

同一角色展示全身正面、侧面、背面三视图，并附三种小型表情研究和服装/材质细节。角色一致、比例统一、视图清晰分开、留白充足，背景为干净的浅暖纸色，不画环境场景。

风格为温暖的手绘 2D 动画插画：深褐色铅笔/墨线带轻微不规则感和粗细变化，形状简洁易读，带克制的纸张与水粉质感。采用自然蓝绿色环境色与低饱和植被色；衣服使用暖奶油色和柔和陶土色点缀，肤色自然柔和。

角色有略大的儿童头部和紧凑身形，五官简化可爱。深色短发略凌乱，以一缕容易辨认的卷发作为识别点；穿实用的奶油色上衣、低饱和青绿色短裤，带一处小面积锈橙色围巾或布料细节。轮廓和色块要在缩小后的游戏尺寸中清晰，细节须便于动画制作。

保持完全原创，不仿照现有电影角色或系列作品，也不复制其构图。避免写实、3D、光亮的动漫质感、过度复杂服饰、满屏渐变、戏剧化特效、遮挡身体的道具、文字、标签、签名、水印、额外肢体，以及不同视图间角色外观不一致。
