# 童年主角探索图 v2 提示词

为我们自己的游戏创作一位全新原创的 5–6 岁儿童主角，主题是珍贵的童年记忆。角色采用经典法国清晰线条动画与欧洲儿童绘本的克制简洁感，不要做成可爱日漫或通用绘本吉祥物。

风格方向：干净清晰的深褐色铅笔墨线，线条变化克制；简洁平涂漫画色块，仅在表面加入轻柔水彩/水粉质感；整体像二维动画，带一点圆润体积感，不要光亮 3D。人物头部略大但不 Q 版，比例符合儿童年龄，四肢短而自然，不夸张。五官简洁：小圆点眼睛、一条弯曲且能表达情绪的眉毛、微小的问号形弯鼻、简单弧线笑嘴；情绪主要由眉毛和嘴部变化表达。栗棕色短发微乱，有一缕易辨认的小卷发。

服装为适合原创虚构游戏的朴素日常乡村穿着，不对应特定年代：柔和奶油色上衣、低饱和蓝绿色短裤、砖红色小围巾、简单棕色鞋。使用草绿、赭石、奶油黄、天蓝和砖红，明快但柔和，避免纯黑。

画面只呈现一个全身站立的孩子，姿势放松、带好奇感，居中，面部和轮廓清楚；背景为浅暖色，仅有柔和手绘地面投影，不要转面图、额外角色或叙事场景。柔和金色午后光，怀旧、温柔、克制。

只借鉴宽泛的法国漫画/欧洲动画视觉原则，不复制或辨认任何现有角色、演员、服装、场景或具体镜头。不要二战符号、制服或武器。避免写实、动漫、漫画大眼、萌系、Q 版、大头比例、粗重描边、复杂明暗、戏剧光效、镜头特效、重颗粒、塑料质感 3D、文字、标签、水印和额外肢体。
