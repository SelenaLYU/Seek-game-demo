# 童年女主角探索图 v3 提示词

为我们自己的游戏重新设计一位原创的 5–6 岁小女孩主角，主题是珍贵的童年记忆。通过有设计感的中国元素童装清晰表达女孩身份，不依赖夸张性别刻板印象。整体借鉴法国清晰线条动画与欧洲儿童绘本的宽泛视觉语言：干净深褐轮廓、克制简洁的形状、点状小眼睛、弯曲表情眉、小弯鼻和简洁表情嘴；漫画式平涂色块配少量水彩/水粉肌理；温和圆润的二维动画体积感。不要日漫、Q版、写实或光亮 3D。

服装是当代、 timeless 的中国元素儿童日常服装，而非戏服：短款立领上衣、不对称盘扣，袖口有低调同色云纹/花纹刺绣；下身为便于跑跳的百褶短裤，或内搭短裤的简单 A 字裙；穿布面运动鞋。以小型桂花刺绣发夹和一处细窄红线/流苏作为克制点缀。剪影实用、独特、亲切且便于动画，细节精心但不过度繁复，不做华丽礼服或仪式服装。

深栗色短波波头，带一条小侧辫和桂花发夹，形成容易识别的剪影。表情温柔好奇，站姿放松，一只手轻轻拿着小布袋。

服装配色严格遵守 6:3:1 色块面积：60% 暖米白/浅青瓷色主布料，30% 低饱和蓝绿或深玉色辅助拼片，10% 朱红色小面积点缀（仅用于发饰、一处小结/流苏和少量刺绣）。保持面积比例清晰，不增加互相竞争的颜色。肤色自然，头发深棕。

画面只出现一个女孩，全身、四分之三正面角度，居中，脸和服装完整可见，背景为干净浅暖纸色，仅有轻微手绘地面投影；不要场景、文字、三视图或其他人物。气质温暖怀旧、安静活泼，柔和金色午后光。角色缩小成游戏精灵图时仍要易辨认；儿童比例可信，头部略圆但不过大，四肢自然短小。

这是原创游戏角色；中国纹样只作细腻装饰灵感，不对应特定历史/民族服饰，不复制任何媒体形象。避免看起来像男孩、校服、刻板旗袍、复杂汉服、过多花纹、大型头饰、首饰、化妆、动漫大亮眼、Q版比例、纯黑硬描边、强烈赛璐璐阴影、复杂背景、文字、标签、水印和额外肢体。
