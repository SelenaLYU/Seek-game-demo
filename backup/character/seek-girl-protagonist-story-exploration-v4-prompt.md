# Seek 女主角叙事探索 v4 提示词

创作原创游戏《Seek》的 5–6 岁女主角全身概念图。故事意义：玩家起初进入一个孩子的普通记忆，探索森林和家庭房间、收集碎片；很久以后才明白，自己是在帮助一位老人找回人生并完成告别。孩子应像一个真实被记住的人，而不是时装角色或吉祥物：好奇、会观察、有一点自己的主意，带着安静的温柔。

表现她在探索途中短暂停下，注视刚发现的一颗玻璃弹珠或小纪念物里反射的微小暖光。神情专注安静，不要大笑。设计一个微小的贯穿人生符号：袖口或布袋上有手工缝的三瓣小花，简单到成年阶段也能自然延续。不要魔法特效，亮光只是普通午后阳光。

视觉采用法国欧洲二维动画气质：清晰线条轮廓，简约而有表现力的点状眼睛、优雅弯眉和简洁嘴形；色块干净克制，背景仅有轻微水彩/水粉质感，角色图形清楚易读。头部略圆但儿童比例自然可信，不做 Q 版。

主色面积按 6:3:1：60% 暖象牙/奶油色上衣与裙裤，30% 低饱和玉色/蓝绿色拼片和鞋，10% 朱红小面积点缀（仅用于发绳和一小段手缝线）。中国元素融入日常穿着而非戏服：不对称布扣、一个小布结、手缝花纹；衣服宽松实用，适合跑跳。不要复杂汉服、刻板旗袍或校服。深色直发齐耳短发，稍微参差，像家里剪的；一侧小发束扎起，形成简洁辨认轮廓。斜挎一个旧布袋，不出现文字。

构图为单人四分之三角度全身像，背景是浅暖纸色，边缘只隐约带一点森林绿和室内暖色晕染，不画完整场景。孩子和手中小物清晰可见。情绪温柔怀旧、儿童视角、柔和午后光，不煽情。

完全原创，不复制任何动画角色、电影、艺术家、具体场景或服装。避免通用可爱吉祥物、大亮眼、动漫、Q版大头、写实、3D、时装大片姿势、装饰过量、夸张魔法、浓重黑描边、高对比、文字、标志、水印、其他人物和额外肢体。
