# 海边 × 江南女主角服装探索 v5 提示词

为原创游戏《Seek》设计一位令人一眼记住的 5–6 岁中国小女孩，融合江南水边童年与海风感。本图为视觉探索，不是最终定稿。全身四分之三视角，姿态自然灵动，像刚被海风吹动衣服；轮廓在小尺寸游戏画面里仍清晰。

整体采用法国欧洲二维动画气质：清晰线条轮廓、克制有表现力的点状五官和弯眉、简洁平涂色块、轻微手绘肌理、温和圆润体积感；不要日漫、Q版、写实或光亮 3D。

服装的辨认剪影：实用的江南灵感短款斜襟上衣，带小布盘扣；搭配方便跑跳的宽松灯笼短裤；外搭一件短款海风披肩/小斗篷，衣角被风轻轻带起。简洁半扎发型上系一条飘动的长青绿色发带。核心识别形状是飘动的发带和短披肩。深色直发，孩子气的齐耳短发半扎。

蓝白江南印花只局部出现在一边袖口拼片和旧布斜挎袋上，纹样简洁细致，像水波与小花的几何组合，不要密集。朱红色只出现一个很小的结饰。穿实用布鞋，不戴首饰。

服装配色面积严格为 6:3:1：60% 暖米白主上衣与短裤，30% 低饱和海玻璃青绿/玉蓝色披肩、发带和小拼片，10% 朱红点缀。蓝印花保持低对比并沿用已有颜色。中国元素应像日常童装细节，而非戏服：斜襟、小布结、局部蓝印花。

角色好奇、有主见、温柔又活泼，和日常童年记忆相连；五官简单而有情绪，不要过度可爱化。背景为浅暖纸色，只有柔和地面影子和极淡海蓝风感色晕，不画详细场景，不加文字标签或三视图。确保全身和服装细节完整清楚。

角色完全原创，不复制现有动画人物、电影服装或任何艺术家的具体作品。避免刻板旗袍、华丽汉服、校服、成人时装造型、大型配饰、过多纹样、过多红色、粗黑描边、戏剧特效、水印、额外肢体和其他人物。
