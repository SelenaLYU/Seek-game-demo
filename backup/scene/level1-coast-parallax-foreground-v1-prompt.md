# 第一关海边近景视差层 v1

参考 `level1-coast-handdrawn-exploration-v2.png` 的构图与配色，单独提取最靠近镜头的前景；用《悠悠长假》动画场景拼图只参考手绘轮廓与概括形状。

```text
Create a standalone, wide 16:9 transparent game foreground overlay that matches the near foreground of reference image 1. Reference 1 provides the composition, palette and object scale; reference 2 provides only the hand-drawn animation line style. This is ONLY the closest parallax layer: clusters of dark blue-green broad coastal leaves, a few reeds, blue-gray and warm brown rounded shoreline rocks, tiny shells and a small shallow tide-pool edge. Use varied scale, overlap and negative space to create a clear near-camera frame and strong depth. Place the richest rock-and-plant clusters at the far left and right lower corners; keep the central bottom band mostly open and transparent so it will not cover the character's walk path. Shapes can rise into the lower 15-25 percent near the edges but stay low in the middle. Transparent everywhere else: no sky, water horizon, village, background color, rectangular strip, or shadow haze. Use hand-drawn dark umber ink contours, simplified matte gouache color shapes, limited visible brush texture, comfortable blue-green/ochre palette. Avoid photorealism, glossy detail, 3D, repeated identical plants, dense grass carpet, text, frame, or character. Produce actual alpha transparency outside the foreground objects.
```

用途：前景视差探索素材。与完整场景概念图搭配测试，需在游戏里调整高度、遮挡范围和横向滚动速度；不作为碰撞地面。
