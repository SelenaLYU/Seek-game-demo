# Seek 家庭记忆房间探索 v1 提示词

创作原创游戏《Seek》的宽幅室内环境概念图：一间朴素、有人生活痕迹的江南家庭记忆房间，以 5–6 岁女孩的视角回忆。风格参考队友认可的美术图：清楚手绘深色轮廓、低饱和平涂色块、克制绘制纹理、法国/欧洲二维动画背景的清晰可读性。不要复刻参考图构图或具体物件。本图不出现人物。

用普通生活物件传递家庭温度，不使用魔法效果。窗边有木桌与柔和日光；墙上有挂钟、旧收音机、家庭合照、日历；桌边有小盆茉莉和玻璃鱼缸。物件间留出清晰间距，每件都能成为游戏中的调查/交互点。加入矮凳、木柜、略有岁月痕迹的浅色灰泥墙、深色木窗框、折叠的蓝白布，以及通向室外绿意的门洞。镜头略侧向，空间简洁，前中景易辨，地面留出清楚可走区域。

深褐细描边，平涂克制色面，阴影使用少量清楚的形状，表面只留少许干刷纹理；不要湿水彩晕染、油亮厚涂、柔焦雾气或光晕。暖米白墙、低饱和木棕、灰蓝绿色点缀，自然窗光；纺织品上可有一点点朱红。安静、温暖、怀旧，但不要豪华或布景感。

避免文字、标签、UI、人物、可读文字、现代电子设备、幻想粒子、写实、3D、日漫、杂乱、道具过多、浓重黑描边。
