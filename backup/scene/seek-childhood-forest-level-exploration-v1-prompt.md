# Seek 童年森林关卡探索 v1 提示词

生成原创叙事游戏《Seek》的 16:9 横版童年森林关卡环境概念图。风格参考队友认可的美术图：清楚手绘深色轮廓、低饱和平涂色面、克制绘制纹理、易读的欧洲二维动画背景。不复制参考图的具体场景、构图、人物或二战元素。本图不出现角色。

场景是一条江南海岸附近的普通森林小路。略带侧视的游戏镜头；画面下半部有一条从左向右清楚、宽阔、不被遮挡的可玩路径，包含缓坡、短倒木和少量低石块作为简单平台元素。一侧有剪影清晰的老樟树和露根，另一侧可见蕨类、低灌木与窄溪。中景放一座简单木桥和通往林深处的小路标。远景由简化树干和低饱和树冠分层，逐渐打开到浅蓝海面与远山。树枝上系一小条红布作为记忆地标。植物按清楚的大形分组，树冠只用两到三种绿色，不要植物图鉴式细节。

深褐色细手绘轮廓，平涂赛璐璐色面，少量简洁阴影形状，大面积仅有轻微干刷纹理；不要湿水彩晕染、空气刷雾、油腻厚涂或光晕。鼠尾草绿、橄榄绿、赭黄土路、蓝绿色溪水、淡天空蓝。自然柔和日光，儿童视角，安静好奇。前中后景清晰分层，适合视差；路径和平台轮廓适合实际游玩。
