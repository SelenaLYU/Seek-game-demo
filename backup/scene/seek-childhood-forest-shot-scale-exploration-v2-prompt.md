# 童年森林景别与镜头变化探索 v2 提示词

仅参考队友美术图的宽泛画法：细深色手绘轮廓、低饱和平涂色块、克制干刷纹理、易读的欧洲二维动画背景。生成《Seek》同一段童年森林小路的 3 格横向分镜，镜头尺度和构图明显不同，同时保持地理连续。无人物、文字或标签。

1. **远景建立镜头**：宽阔森林入口，小路从左下进入并蜿蜒到木桥；老樟树、溪水、分层树冠，远处隐约可见淡色海面；路线是清楚可玩的横向通道。
2. **中景**：靠近木桥和路标，溪水与蕨类更明显，树干框出路径；树枝上有一小条红布作为记忆标记。
3. **近景/儿童低视角**：前景树根、踏脚石、倒木、小花与溪边细节清楚，小路从画外延续；平台尺寸有参照感。

三格是同一地点的连续镜头，而非三片不同森林。植被用成组的大形，树冠只用两到三种绿色，避免植物细节过密。强调游戏可读性和视差层。鼠尾草绿、橄榄绿、赭黄土路、低饱和蓝绿水、粉笔浅蓝天。自然柔光随景别轻微变化：远景林间开口较明亮，中景有树叶斑驳影，近景偏清凉树荫。

使用清楚的深褐细手绘轮廓、平涂色块、少量干净阴影形状，只加极轻干刷肌理。避免湿水彩、油腻厚涂、空气刷雾、光晕、厚重渐变、写实、3D、日漫、粗黑描边、杂乱、人物、文字、UI、水印。三格之间用简单浅色留白分隔，不做装饰边框。
