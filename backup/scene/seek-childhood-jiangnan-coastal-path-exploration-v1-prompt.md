# Seek 童年江南水岸场景探索 v1 提示词

参考附件仅用于角色/整体绘本风格：保留温暖水彩儿童绘本感、柔和墨线、自然儿童比例、轻快动作，以及简单的奶油色中式上衣与蓝绿色短裤。本图只生成原创游戏《Seek》的 16:9 横版 2D 童年记忆关卡环境概念，不出现角色。

场景是一条安静的午后小路，位于江南水乡河道旁，水道在远处连向海湾。下方三分之一有连续、易读的泥土石板路，少量低矮踏脚石与小水洼；地面清楚、留有跑跳空间。中景是白墙灰瓦老屋、木门、简朴小码头、柳枝、小木船、芦苇，以及门边晾着的一块蓝白布。远景河道逐渐展开至浅蓝海平线，配低矮青山、少量帆影与柔软云朵。设置一扇像家的门或温暖窗光作为情感目的地；水边木桩上系一小条红布，作为细微的记忆地标。整体有人生活的普通感，不像旅游明信片或幻想世界。

采用法国欧洲二维动画背景的手绘水彩/水粉质感，轻柔松动的墨线，建筑形体简洁清楚，纸张肌理轻微，笔触细节克制，远近有柔和空气层次。配色为暖奶油白墙、灰蓝瓦、柔和新柳绿、蓝绿色水面、浅蓝天、赭黄色泥土路，少量朱红点缀。自然午后光与柔和阴影，温柔怀旧的儿童视角。

布局适合视差拆层：前景草叶与石边，中景道路/房屋/码头，远景山与海。中部保留干净的横向移动通道，不让物件挡住可玩地面；画面信息清晰但不拥挤。
