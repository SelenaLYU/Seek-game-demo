# Seek 江南海岸童年场景 v2 提示词

附件仅作宽泛画风与关卡构图参考：清楚的手绘深色轮廓线、平涂低饱和色块、轻微绘制纹理，以及前中后景分层的可读 2D 横版游戏空间。不要复刻参考里的建筑、角色、物件、二战设定、镜头或构图。

为叙事向 2D 冒险游戏《Seek》创作一张原创 16:9 横版童年关卡场景。地点是江南水边村落与海湾相接处，从略高的侧视游戏镜头观察，不要像旅游明信片。画面中部有清楚、蜿蜒的土石小路作为横向可玩路线，留出宽敞安全的地面和少量低矮可跳石块/木头。一侧是简洁的白墙灰瓦家宅和木院门；房屋后方可见窄河道、一只小木船、低石岸与芦苇。另一侧是一棵有树荫的大柳树、灌木和低矮篱笆。远景为简化的浅绿山丘与一线蓝色海面、天空。篱笆柱上系一条小红布，是唯一鲜亮点缀和记忆地标。建筑可信、疏朗，不要塞满房屋。

画法：清晰利落的深褐/炭灰手绘细描边，有控制的线条变化；轮廓简明易读；平涂赛璐璐色面，阴影只用少量清楚形状；大面积表面仅有轻微干刷纹理。不要湿水彩晕染、油亮厚涂、奶油空气刷雾、柔焦或光晕。参考传统欧洲二维动画背景的图形清晰度与克制肌理。配色沉静但清楚：粉笔感暖白墙、灰赭土路、鼠尾草绿和橄榄绿、蓝灰绿水面、灰蓝瓦顶、小面积砖红点缀。自然日光、均匀照明。

场景适用于实际游戏：玩家通道无遮挡，前景草仅从画面边缘框景，不阻挡路线；平台高差和出口容易读。视差前中后景简洁分明。无人物、文字、UI、标签、边框、水印、戏剧性夕阳、写实、3D、日漫、过多水彩、过度装饰、粗黑描边、电影光晕、浑浊配色或对参考图的具体复制。
