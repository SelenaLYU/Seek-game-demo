# 家庭记忆房间朝向与光影探索 v2 提示词

仅参考队友美术图的宽泛画法：细手绘深色轮廓、简化低饱和平涂色面、克制干刷肌理、欧洲二维动画背景的清晰度。生成《Seek》同一间江南家庭记忆房间的 2×2 分镜联系表，每格相机朝向和日光时段不同。房屋结构、家具和物件摆放保持足够一致，使四格明显属于同一房间。不要人物、文字或分格标签。

1. **从门口朝窗户和木桌的广角**：清晨阳光从左侧进入。
2. **从窗边反向看房间入口和旧木柜**：阴天漫射光，阴影偏冷。
3. **横向看桌面、挂钟、旧收音机和家庭照片**：傍晚暖阳形成较长但简洁的影子。
4. **从矮凳旁的儿童低视角看桌子/鱼缸和门口**：安静的蓝色暮光，只有小台灯或窗外暖光。

同一套房间物件：木桌、旧挂钟、收音机、相框、日历（不出现可读文字）、盆栽茉莉、玻璃鱼缸、矮凳、深木窗框、略旧的浅色灰泥墙、折叠蓝白布。镜头是真正不同朝向，不只是换颜色；空间关系须连贯。以窄浅色留白分隔四格，不要标题、标签、UI 或水印。

风格为深褐细手绘线、平涂色块、少量清楚阴影、极轻干刷肌理。不要湿水彩晕染、油画感、空气刷、模糊或光晕；实用灯光可保留克制光源。暖米白墙、木棕、低饱和蓝绿点缀；每格明确表现光线方向与影子位置。原创环境，不复刻任何动画中的具体镜头。
