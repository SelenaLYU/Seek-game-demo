# Seek 广州西关街巷童年场景探索 v1

使用队友认可的参考图作为宽泛画法参考：清晰手绘深色轮廓、低饱和平涂、简化易读的背景形状和横版关卡构图。不要复制参考图中的欧洲建筑、人物、故事、镜头或历史细节。为原创游戏《Seek》创作一张 16:9 横版童年记忆关卡，地点是有人生活气息的广州老西关街巷。不要人物、文字、标签或 UI。

**岭南/广州识别点**：一排连续的旧骑楼商铺，街侧有遮雨骑楼廊和简洁柱列；上层浅色灰泥墙、下层青灰砖墙；一扇打开的门内隐约看到西关大屋天井和一格彩色满洲窗；一棵遮住小石巷的老榕树；窄雨水沟与小石桥/踏步；一处屋脊上克制出现的灰塑细节。骑楼廊下可以有一只小荔枝篮或纸风筝作为普通童年线索，不做旅游陈列。

略高的侧视游戏镜头；石板街从画面中部清楚地横向延伸，作为无遮挡的可玩路线；骑楼廊道提供连续安全路径，少量低门槛/台阶形成简单平台变化。前景边缘只放几片叶或小凳，不阻挡移动。中景建筑是视觉重点，远处用潮湿空气里的屋顶绿意和浅色天空收尾。街巷有熟悉、温暖、树荫下雨后微湿的日常感。

**画法**：利落的深褐炭笔手绘细轮廓，平涂色面，克制的双色阴影，只有极轻干刷纹理；砖石和建筑剪影清楚易读。不要湿水彩晕染、油亮厚涂、空气刷雾或电影光晕。粉笔奶油白、冷灰砖、灰鼠尾草色、榕树绿、褪色蓝绿窗板、灰赭石板路，极少朱红点色。保持法国/欧洲二维动画背景的清晰可读性。

避免细节过密、杂乱、现代摩天楼、霓虹招牌、旅游灯笼、节庆舞龙舞狮道具、奇幻建筑、粗黑描边、3D、写实、日漫、文字和水印。场景为受广州建筑启发的原创虚构街巷，不复刻某条具体街道。
