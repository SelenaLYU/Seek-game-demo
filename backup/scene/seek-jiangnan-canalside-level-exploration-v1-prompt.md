# Seek 江南临水街巷场景探索 v1 提示词

参考用户图片的空间布局：两岸临水建筑、开阔平静的河道、河道向远处收束、天空与水面倒影。将其转化为《Seek》原创手绘 2D 横版游戏场景。不照抄照片，不保留真实人物、具体建筑、招牌、灯笼摆放或写实渲染。

画面为 16:9 江南水乡童年记忆关卡，略高侧视游戏镜头。中央是平静运河，两岸有窄石岸和临水民居；水道向远方的小拱石桥与柳树弯道收束。近岸下方三分之一是一条清楚连续的石板路，横向贯穿画面，少量低台阶和木平台，足够宽且无遮挡，适合孩子跑跳。对岸是简洁白墙、深灰瓦、木窗板和朴素檐廊；一处打开的院门露出安静天井。加入一座小石桥、两只系泊小木船、水生植物和一棵大柳树，控制道具数量。窗边晾一块蓝白布，作为家庭记忆细节。无人、船上无人。像普通生活记忆，不是旅游明信片。

画风沿用团队认可的二维动画参考：清晰细致的深褐色手绘轮廓线，简洁易读的建筑剪影，低饱和平涂色面，少量明确阴影，极轻干刷纹理。不要亮泽湿水彩、油画感、空气刷雾、写实或 3D。柔和但清楚的日光；粉笔奶油墙、板岩灰屋顶、低饱和柳绿与苔绿、蓝绿色水面、浅蓝天空、暖灰赭色石板。水面倒影用宽阔概括的平面形状，不画照片级细碎波纹。

中景建筑易读，近岸有明确可玩通道；前景植物只在边缘，不挡路。前景/中景/远景适合视差拆层。避免文字、UI、标签、水印、边框、过多灯笼、节庆装饰、浓重黑描边、日漫、电影光晕和拥挤集市。
