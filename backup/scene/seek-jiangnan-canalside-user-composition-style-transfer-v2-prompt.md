# 江南水巷原图构图风格转换 v2 提示词

将用户提供的江南运河照片转绘为《Seek》手绘二维动画背景概念，紧密保留原参考的构图和空间关系：前景/中景是连续宽阔的运河水面，两岸排列临水房屋，河道透视向远处收束，保留开阔天空和水面倒影。水面必须保持连续开阔，不添加桥、横跨物、栈道、平台、踏脚石、前景小路、码头、岛屿或任何阻断河道的物件。近岸只保留照片中实际存在的河岸边线。移除真实人物和照片瑕疵，其余建筑体量和位置忠实沿用参考图。

只转换画风：清晰细致的深褐色手绘轮廓，简化易读的房屋和屋顶形状，低饱和平涂色面，克制的双色阴影，极轻干刷肌理。匹配团队认可的法国/欧洲二维动画背景参考。不要亮泽水彩、油画厚涂、空气刷雾、写实或 3D。颜色沿用原图并稍作简化：清亮蓝天、低饱和蓝绿色河水、暖灰石岸、浅色灰泥墙、炭灰屋顶、克制绿植。自然日光，倒影用概括的平面形状表达，不做照片级细节。

不要改变相机角度、地平线、河岸位置、河面宽度、屋顶轮廓或整体构图。不要添加人物、原图中没有的船、文字、招牌、标签、UI、水印、边框、桥、平台、横跨水面的路、节庆灯笼或额外前景元素。成图应当像同一个用户提供的地点被重新画成已认可的动画风格。
