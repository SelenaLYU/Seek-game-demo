# 江南水巷手绘笔触强化 v3 提示词

以队友提供的动画场景拼图作为手绘笔触参考：可见且有压力变化、轻微抖动的墨线轮廓；短促断续的排线；手工铺色留下的不均匀边缘；树叶、石头、屋顶和水面都有少量方向明确的笔刷痕迹。画面应像动画师手工勾线并上色，而非干净矢量图。

场景仍基于用户提供的江南运河照片：前景与中景是宽阔连续的水面，两岸临水房屋沿运河分布，透视向远处收束，保留开阔天空和水面倒影。构图、视角和空间布局尽量跟随原照片，不加桥、横跨物、栈道、平台、踏脚石、前景小路、码头或打断水面的物件。移除真人和照片瑕疵，保持原有建筑体量和位置。

画法：松动但有把握的手绘墨线，线条粗细轻微变化，少量断线/复线体现自然笔触；用短笔刷和排线描绘屋瓦、旧墙灰泥、树叶、石岸和水波。色面保持低饱和、概括清楚，但铺色中能看见细微刷痕、颗粒和不齐边缘；阴影边缘带干刷质感。常规观看尺寸下应能清楚看见手绘笔触。细节选择性出现，不要噪点化。

配色沿用原场景：粉笔暖白墙、去饱和炭灰瓦、蓝绿色水面、清浅蓝天、克制绿植、暖灰石岸。自然日光。水面倒影用松动横向断笔表现，不要光亮写实反射。

避免矢量般的干净边缘、完全平滑色面、均匀机械描边、塑料 CGI、写实、油腻厚涂、湿水彩大块晕染、奶油雾气、空气刷、光晕、强渐变，以及任何新增场景物件、桥、前景障碍、文字、UI、水印和边框；不要复制风格参考中的建筑或人物。
