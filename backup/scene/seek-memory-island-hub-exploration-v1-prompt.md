# Seek 记忆之岛枢纽探索 v1 提示词

为叙事游戏《Seek》创作原创 16:9 记忆之岛环境概念图。记忆之岛是连接人生章节的中央枢纽，画面为略高的斜俯视角，表现小岛整体与可探索路径，不出现人物、标签或文字。风格参考队友认可的美术图：清楚手绘轮廓、简洁低饱和平涂色面、克制绘制纹理、欧洲二维动画的清晰度。不要复制任何具体艺术作品、人物或建筑。

小岛被平静的蓝绿色海水环绕，柔和起伏的地形上有蜿蜒小路串联五到六座不同但朴素的记忆建筑：靠近树的童年家庭屋、类似学校的建筑、小型工作空间、后期生活的家，以及远处被薄雾轻轻遮住的老屋。呈现早期游戏状态：多数建筑灰白、褪色、安静未苏醒；前景附近只有童年建筑刚刚恢复少许温暖颜色，窗户有一小点灯光。道路和岸线引导视线环岛，建筑之间留有足够空地和可走动空间。加入稀疏树木、小码头、安静草地、几块石头、简单云朵和淡色远方地平线。剪影清楚，避免拥挤的微缩模型感。

细致的炭褐手绘轮廓，干净简化形状，平涂色面，少量阴影块，极轻干刷肌理；不要水彩晕染、厚重油画、除童年屋微弱窗光外的氛围光效。鼠尾草绿、蓝灰绿海水、粉笔奶油白、灰色未唤醒建筑；仅在刚苏醒的童年建筑附近用克制赭黄/砖红。氛围安静、回望、带希望，记忆之间留白。

避免幻想城堡、漂浮粒子、戏剧夕阳、写实、3D、日漫、标签、UI、文字、人物、杂乱、粗黑描边。
