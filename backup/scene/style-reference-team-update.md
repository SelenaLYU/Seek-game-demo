# 美术参考笔记｜人生记忆游戏

版本：2026-09-30 · `backup` 分支试验方向稿。所有人物与场景图仍在探索阶段，尚未获得最终资产确认；时代背景、后续人生阶段和正式导出规格未定。

## 项目背景

新游戏以 [Recall game demo](https://github.com/SelenaLYU/Recall---game---demo) 的场景切换、互动探索和记忆收集框架为基础，重新设计故事与画面。玩家扮演同一位主人公，经历人生的不同时期；每个时期的玩法可以不同，但都让玩家亲自参与一件看似普通的小事。回望时，这些片段共同呈现“珍惜拥有的时间”。《查克的一生》是情感主题参考，不要求照搬它的叙事顺序或情节。

## 核心感受

以《悠悠长假》的温暖手绘语言为造型参考，再吸收《空想新子和千年的魔法》的蓝绿自然光色，表现一个人一生中平常而珍贵的时刻。画面要能承载安静的日常，也能在回忆时显出情绪重量。两部作品都是视觉气质参考；游戏的人物、地点、服装、道具和具体构图都要重新设计。

## 从参考画面提炼的语言

- 轮廓：深灰或深褐色的手绘线条，粗细有变化，保留少量不规整的笔触；避免机械直线和过度锐利的边缘。
- 色彩：大面积柔和、偏自然的中低饱和色；树叶可分成浅黄绿、灰绿、深墨绿几层，天空与暖色墙面提供呼吸感。重要交互物件使用少量更暖或更亮的颜色突出。
- 材质：墙砖、屋瓦、木板、草地留可见的轻微纹理与生活痕迹，细节集中在近景和可交互区域，远景保持概括。
- 空间：用道路、围栏、门窗与树冠组织画面，远近层次清晰；角色活动区要比参考截图更明确，避免背景细节淹没玩法。
- 光线：偏自然的漫射日光与柔和阴影；不同人生阶段可以改变季节、时段、气温和光色，但保持同一套线条与材质语言。
- 情感锚点：每个阶段挑少量普通物件反复出现或产生变化，让美术直接服务“日常记忆值得珍惜”的主题。

## 多组画面对照后的具体观察

以下来自小红书多篇帖子的剧照，以及制作资料的交叉核对；帖子标题里的评分、剧情感受不作为美术依据。

| 观察对象 | 稳定出现的做法 | 转成游戏资产时 |
| --- | --- | --- |
| 乡村外景 | 天空常是较干净的浅蓝与大块白云；远处树群颜色浅、轮廓简，近处树冠更深、更密。道路和篱笆把视线引向房屋或人物。 | 背景至少分三层；保留足够安静的天空与远景，行走层和交互物更清晰。 |
| 建筑 | 房屋体积清楚，墙体用奶油白、砖红、棕灰交替；屋顶、窗框、木门和砖缝都有少量磨损线与色块变化。 | 先画可读的整体剪影，再加窗、门、砖与旧化纹理；每个建筑保留自己的辨认点。 |
| 植被 | 树叶不是一整块绿色，而是多层团状形、深浅冷暖错开；草地以短促笔触、影子和少量裸土打破平涂。 | 做可重复的树冠、灌木、草簇模块，但避免完全相同的轮廓连续贴图。 |
| 人物 | 角色比背景更简洁；脸部细节少，动作、发型和衣服色块负责辨认。儿童身形有略夸张的头身关系。 | 主角必须在游戏显示尺寸下仍能被识别；跨年龄用发型、姿态或惯用颜色延续身份。 |
| 日常场面 | 房屋、树荫、野餐布、篮子、手推车等普通东西共同讲故事；场面温暖，但阴影与深色区域仍占一定比例。 | 用少量有交互意义的普通物件组织情节，不靠满屏发光粒子来表示“回忆”。 |

制作方将作品描述为 **3D 制作、呈现 2D 绘画效果**。因此我们要参考的是最后画面的轮廓、色块和质感，项目并不必采用同一套制作技术。

## 第二组参考：《空想新子和千年的魔法》的蓝绿色调

在小红书多组剧照里，最鲜明的关系是**青蓝天空、鲜活的黄绿田野、灰绿远山与蓝绿阴影**。色彩有明暗和冷暖层次，并非全画面统一染成青色。晴天的白云与浅色道路留出呼吸空间；人物的肤色、橙红或粉色衣物是小面积的暖色落点。水面、幻想或回忆画面可更偏青蓝，但常规日景仍要保留自然物本来的颜色。

| 用色位置 | 建议处理 | 游戏里的作用 |
| --- | --- | --- |
| 天空与空气 | 明亮青蓝、浅蓝到近白云边，面积大但纹理轻。 | 给田野和村庄开阔感，让角色轮廓读得清。 |
| 草地与田野 | 日照处是浅黄绿或嫩绿；背光处转到青绿，局部露出泥土色。 | 让童年场景有生命力，也让可走的路从草中显出来。 |
| 树木与远山 | 近景树冠用深绿、蓝绿叠层；远山更灰、更浅、更少细节。 | 拉开远近，同时给明亮场景足够的暗部。 |
| 水与阴影 | 水面可用偏青蓝的浅色，树荫用冷蓝绿或灰绿；避免纯黑阴影。 | 统一环境色，并区分清凉、静谧的空间。 |
| 人物与记忆物件 | 肤色、衣服、木头、便当盒等保留少量米黄、陶土橙、粉红或砖红。 | 冷色环境中形成情感焦点；交互点不必靠荧光描边。 |

第一轮**提案色票**（按观察重新设计，**不是电影官方取色**）：天空 `#83CDE3`、云与纸白 `#F5F1DE`、阳光嫩绿 `#B8D871`、草地青绿 `#5C9E7B`、树荫深蓝绿 `#285F5E`、远山灰绿 `#86A89B`、暖色点缀 `#C77754`。这些只用于风格测试，最终值以实际场景、游戏尺寸和角色可读性调整。

**两组参考的组合原则**：《悠悠长假》负责轮廓、建筑、材质与手绘笔触；《空想新子和千年的魔法》负责天空—植被—阴影的蓝绿气氛。童年可更明亮、青绿；后续人生阶段可改变季节和明度，但保留青绿环境色作为视觉线索。回忆的珍贵感通过暖色物件和光线对比表达，避免每个阶段都套相同滤镜。

## 当前试验方向：年年与开场海岛

以下记录最新讨论结果，方便团队看试验稿时分清“正在尝试”与“已确认”。

- **主人公年年**：约七岁、在海岛渔村玩耍的小女孩。保留棕色眼睛、清楚的小鼻子、鼻梁和两颊可见的细小雀斑、晒红的脸蛋与轻微闭嘴笑容；米白短袖中式斜襟上衣、灰青绿色宽松短裤、赤脚。人物画风和低饱和色彩以近期设定稿为基准，不再随发型改动而整体换色。
- **发型最新探索**：`character/niannian-model-sheet-v9-soft-wavy-bob.png` 是不扎辫子的蓬松波浪卷短发版本；此前双麻花辫、鱼形布袋、围巾和紧密爆炸卷等版本均在 `character/` 留作对照。**最新版本仍未最终确认**。
- **开场场景**：一个有生活气息的小渔村海岛，包含沿岸民居、渔船、码头、晒网与岛民日常，不走无人海滩或度假村视觉。镜头**正对海面**，从下至上是前景沙滩、中景阳光闪烁的海水、远景错落的小岛和渔村；天空开阔，绿色椰树只作配角，不用巨大近景树干遮画面。年年赤脚快乐奔跑，但在大远景里应保持较小比例。
- **色彩与画法**：蓝天、蓝绿色海水、灰绿远岛、暖浅沙滩；沿用《悠悠长假》启发的自然手绘轮廓、旧化纹理和朴素色块，不给人物加高饱和颜色或 glossy 动画高光。具体建筑与人物设计保持原创。
- **制作状态**：目前都是概念图／三视图试验稿，并非已分层的游戏背景或通过透明边缘检查的最终角色资产。人物发丝周围曾出现模糊像素和透明边缘杂色；正式制作前须清理轮廓、确认 alpha、在游戏显示尺寸下测试可读性。

所有 16 张生成试验稿及其逐图原始提示词见 [asset-prompt-log.md](asset-prompt-log.md)。

## 对游戏资产的初步要求

- 场景背景：分远景、中景、可行走层和前景遮挡层，便于视差与互动。
- 人物：不同年龄保持可辨认的共同特征；角色轮廓与背景有足够对比。
- 物件：区分纯装饰、可调查、可拾取、关键记忆四类，互动状态要能一眼看出。
- UI：像日记、旧照片或手写便笺一样融入世界，但正文与按钮必须清晰可读。
- 动画：小幅度的风、树叶、布料、光斑和人物动作，比持续夸张的特效更符合主题。

## 第一轮资产清单（类型，不预设具体剧情）

1. **风格测试图**：同一原创场景的全景、角色近景与一个可互动日常物件，用来确认线条、色彩、光线和信息密度。
2. **主人公设定**：各年龄段轮廓与服装探索，先解决“同一个人”的视觉连续性。
3. **阶段场景**：每个时期各有一张氛围图，再拆分为游戏可用的层与物件。
4. **记忆物件**：每段至少一件可互动的小东西，既能承担玩法，也能在结尾成为情感线索。
5. **基础 UI**：对白、调查提示、收集反馈与章节切换；先做可读性测试，再加装饰。

## 给制作与评审的共同标准

- 缩小到实际游戏画面时，角色、道路和交互目标仍清楚。
- 暖意来自光线、人物关系和细节，而不只是给画面统一加黄色滤镜。
- 纹理帮助辨认材质，不覆盖角色动作和交互提示。
- 不同人生阶段可以变换色温与季节，但轮廓处理、阴影方式和材质颗粒保持一致。
- 参考原作的视觉方法，避免直接复用剧中人物、建筑、剧照或逐帧临摹。
