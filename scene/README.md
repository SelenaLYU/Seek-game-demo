# Scene assets

## `level1-coast-main-background-v1-1900x540.png`

第一关海岸主场景的已确认背景版本。

- 游戏世界尺寸：`1900 × 540`
- 单次镜头尺寸：`960 × 540`
- 用途：随世界坐标横向滚动的完整背景板
- 左侧小型礁石是年年的出生和起跑位置
- 底部沙滩与零散礁石只承担前景景深，不构成连续跳跃路线
- 可跳礁石、海鸥、动态浪尖、钥匙和出口需要作为独立游戏元素叠加

美术方向为低饱和蓝绿色海面、暖色日光、概括的手绘轮廓与水彩铺色。画面避免密集细线，中心及右侧保留开放空间，供关卡元素和角色动画使用。
