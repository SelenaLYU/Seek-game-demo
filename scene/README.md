# Scene assets

## `level1-memory-room-night-empty-v2-1920x1080.png`

**第一关记忆之房夜晚空背景**，不包含录音机、墙画、童话书、相框、带锁盒子、鱼缸或书桌谜题物件。

- 游戏背景尺寸：`1920 × 1080`
- 用途：第一关记忆之房的环境底层
- 光照：蓝白色月光，保留可读的家具和地面层次
- 所有交互物由程序使用透明 PNG 独立叠加
- 资产清单与分层规则见 `art/level1-memory-room-assets.md`

## `room-scene-v1-1920x1080.png`

**房间场景**，当前正式确认版本。

- 游戏背景尺寸：`1920 × 1080`
- 用途：第一章年年房间的完整场景背景
- 画面内容：江南普通人家的儿童卧室，包含单人床、书桌、开放书柜、透明鱼缸与充足的室内活动空间
- 画风延续第一关海岸背景的水彩水粉手绘方向，使用概括色块、纸张颗粒和少量不规则深炭色勾线
- 蓝白墙面、自然木色、珊瑚粉与青蓝色点缀共同构成固定配色
- 光影小船、墙画、尺子、手电筒、画笔等可交互物件继续作为独立图层接入，不烘焙进背景
- 详细画风、构图和生成说明见 `art/room-scene.md`

## `level1-watercolor-game-background-v1-1900x540.png`

**第一关水彩游戏大背景**，当前正式确认版本。

- 游戏世界尺寸：`1900 × 540`
- 单次镜头尺寸：`960 × 540`
- 用途：第一关海岸场景随世界坐标横向滚动的完整背景板
- 左侧小型礁石是年年的出生和起跑位置
- 前景石块以连续岩群表现，只勾岩群外轮廓，不逐块包边
- 中央及右侧海面为可跳礁石、海鸥、动态浪尖、钥匙和出口等独立元素留白
- 固定画风与生成提示词见 `art/level1-watercolor-style-prompt.md`

## `level1-coast-main-background-v1-1900x540.png`

第一关海岸主场景的早期确认版本，保留用于版本对照；正式使用以上水彩版本。

- 游戏世界尺寸：`1900 × 540`
- 单次镜头尺寸：`960 × 540`
- 用途：随世界坐标横向滚动的完整背景板
- 左侧小型礁石是年年的出生和起跑位置
- 底部沙滩与零散礁石只承担前景景深，不构成连续跳跃路线
- 可跳礁石、海鸥、动态浪尖、钥匙和出口需要作为独立游戏元素叠加

美术方向为低饱和蓝绿色海面、暖色日光、概括的手绘轮廓与水彩铺色。画面避免密集细线，中心及右侧保留开放空间，供关卡元素和角色动画使用。
